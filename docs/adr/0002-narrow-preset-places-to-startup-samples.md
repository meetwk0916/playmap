# 将预制地点收敛为九个启动样例

预制地点只用于避免新地图空白，不表示质量排名或正式推荐。目标名单为九个明确类别各一个：单个样例须位于上海、绑定确切地点身份、类别明确、长期存在且对公众开放；优先选择初始地图视野内或附近的地点，不设置其他配额；新增或替换时核验，之后仅在收到报告或发现变化时复查；具体名单由数据责任人维护，某类别没有合格地点时宁可暂缺也不降低门槛。名单变化受 [ADR-0001](0001-preserve-existing-places-when-preset-list-changes.md) 的已有地点保护约束。

现役规则见 [公开到访内容维护](../public-places.md)：新地图不再预制启动样例；旧数据只移除完整匹配默认指纹且没有个人使用或修改的样例，归属不明保留。
