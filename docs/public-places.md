# 11 到访内容维护

维护者编辑根目录的 `public-places.json`，确认内容后随网站发布。不需要账号或后台；普通用户的个人地点仍只保存在其浏览器。

当前正式名单为空，统一头像也为空。没有真实素材时保持为空，不把旧预制点或测试数据填成 11 的经历。

## 一次更新

1. 确认 11 真实到访的地点，绑定确切腾讯 POI（名称、地址、GCJ-02 坐标和类别）。
2. 根据带 11 到访的真实体验填写两个独立等级及理由；未体验或无法判断的维度留空。
3. 需要时补充年龄参考、到访日期、一句体验、资料来源与核实日期。资料和体验冲突时在 `notes` 中说明，不靠程序改分。
4. 使用仓库内可公开的照片，`avatar` 填相对图片路径；所有公开点共用一张。程序居中裁成头像；图片缺失或无法读取时显示“11”。不接受站外头像地址。
5. 运行 `npm run check:design` 和 `npm test`，查看手机详情，确认后按项目发布流程提交和部署。修改文件本身不等于已经上线。

## 格式

下面只是格式示意，不是可发布的真实地点，请替换所有示意值后再加入名单。

```json
{
  "avatar": "assets/11-avatar.jpg",
  "places": [{
    "provider": "tencent",
    "poiId": "确切腾讯POI编号",
    "name": "维护者确认的真实地点名称",
    "address": "真实地址",
    "category": "park",
    "lat": 31.23,
    "lng": 121.47,
    "facilities": { "parking": "yes", "stroller": "limited" },
    "visitedOn": "2026-09-01",
    "experience": "一句真实体验，可省略",
    "child": { "level": "high", "reason": "儿童参与内容的真实体验", "ages": "年龄参考，可省略" },
    "parent": { "level": "medium", "reason": "带娃便利和麻烦点的真实体验" },
    "notes": "体验与资料的差异或需要补充说明的事，可省略",
    "sources": [{ "title": "场馆资料或实地确认", "url": "https://example.com", "checkedOn": "2026-09-05" }]
  }]
}
```

`child`：`high` 很友好、`medium` 较友好、`low` 有限；`parent`：`high` 很便利、`medium` 较便利、`low` 较费心。等级需同时有理由才展示，否则为“暂无评估”。未评估维度可用 `null` 或省略；不算总分，不按设施数目算等级。

年龄、日期、体验、补充说明和来源数组都可省略；有引用资料时保留真实来源和核实日期。电话／现场来源可以没有 URL。便利设施只使用 `parking`、`stroller`、`toilet`、`nursing`、`food`，值为 `yes` 或 `limited`；未知省略，不猜测。

类别继续使用公园 `park`、游乐场 `playground`、动物园 `zoo`、水族馆 `aquarium`、博物馆 `museum`、科技馆 `science`、图书馆 `library`、商场儿童区 `mall`、亲水玩沙 `water`、其他 `other`。

## 更新与撤下

同一腾讯 POI 更新原记录，不添加重复记录。撤下时从公共名单移除：没有个人保存关系的图钉消失，用户已经保存的个人副本继续显示普通图钉，公共评估不会复制成个人评价。

历史预制识别仅采用完整已发布默认指纹。旧随机 ID、任何额外字段、评分／记录／照片或个人修改都保留，不能为减少图钉按名称强制删除。
