# 11 到访地图设计讨论

这里说明现役视觉与布局，并保留原型决策。浏览流程见 [README](../README.md#产品范围)，到访数据见[内容维护](public-places.md)，部署证据见[发布记录](releases.md)与原 PR。

## 当前地图优先界面

- **地图与工具**：首屏框住全部完整到访地点，不自动选点，为顶栏和胶卷留出空间。底图保留道路和地名、隐藏 POI 标注。右侧是指南针、缩放和按需定位；窄屏或粗指针设备隐藏缩放按钮，指南针只在地图旋转或倾斜时显示。「更多」菜单提供「数据与隐私」。
- **胶片相机视觉**：胶片黑顶栏和片基、胶卷盒黄计数窗与选中类别、相纸白照片边框。未选图钉按地点固定微斜，边框用类别色并带类别 emoji；选中时摆正放大，以珊瑚描边对应选中画格。图钉尺寸为 44×54 和 60×74。
- **足迹胶卷与列表**：胶卷有上下齿孔，日期压印在照片内。桌面片基随画格数量伸展，最长不超视口；打开抽屉时胶卷让位。足迹缩略图用白边斜置印样，城市标题配色标和等宽计数。
- **详情与回放**：类别用带 emoji 的浅色标签，日期和年龄保留可读文字；照片使用白边相纸和装饰性日期压印，小草莓在右上角。打开详情时显影，减少动态时关闭。主按钮是「下一个地点」，导航是独立图标按钮。回放用胶片黑虚线和珊瑚色已走路段，当前站高亮为黄色。

页面使用 `mapStyleId: 'style1'`，保留 `base` 与 `label`。维护者于 2026-10-31 确认它对应腾讯云样式 `38089`（「11地图-经典轻调道路」）：弱化道路与地铁，不用整图滤镜。样式与浏览器 Key 绑定；回退时移除显式 `mapStyleId`，无需删除云样式。

## 界面原型

后续视觉调整先保留原页面作为对照，用相同内容和手机尺寸制作一个局部修改版；先评阅再扩大改动。照片位置、信息顺序和装饰占比按已确认版本控制。除非维护者明确要求整体改版，不同时探索多个全新布局。

初期评阅否决了浮动详情、地点目录并排和照片优先三种整体改版；保留地图首页、类别胶囊、头像图钉与底部详情抽屉。后来 [Issue #64](https://github.com/meetwk0916/playmap/issues/64) 选底部足迹带而非紧凑浮标或半页照片，形成现役胶卷。旧原型分支和启动方式不是现役入口；从 [README「运行」](../README.md#运行) 启动对照。

核验腾讯地图原生控件的位置时，除了 Playwright 替身，还要打开真实腾讯地图预览：SDK 的变换容器会影响 `position: fixed` 的定位基准。窄屏与宽横屏分别确认粗指针条件实际生效；模拟安全区不等于 iOS Safari 真机。
