## 已确认

- 访客仅浏览 11 已到访地点，保留地图缩放、拖动和地点详情；去掉搜索新地点、添加地点及个人地图入口。旧个人数据保留，不删除。
- 地点须同时具备已确认的 11 实地到访、一张到访打卡照、维护者提供的 11 评分和准确到日的到访日期才在地图显示。缺项记录留在维护端待补，不从旧体验推算评分；只知道月份时不猜日期或年龄。
- 保留类别筛选、我的位置、地点列表和详情中的类别。类别筛选与地点列表只针对符合上图条件的 11 地点；定位仍须用户主动点击。
- 后续评阅修订：保留导航按钮，放在照片之后的详情最底部；去掉复制目的地。评分详情沿用原始布局，用少量暖色与装饰增加轻快感。
- 每个地点一条记录、一张照片，并附到访日期和打卡年龄。多次到访时，日期与年龄对应所选照片的那次到访，评分表达维护者对地点的整体感受；不增加到访历史时间线。
- 维护者提供的出生日期为 2024-06-11，用于计算到访当天已满的年月。日期和年龄放入略倾斜的草莓形打卡章，显示如「2026.09.12」「2岁3个月」，不显示天数。草莓使用内置 imagegen 生成的手绘透明底贴纸，日期、年龄保持为页面文字。后续评阅要求草莓缩小、降低视觉存在感，移至详情页右上角；不再覆盖照片、不另占一行、不下移照片。
- 保留底图道路、地名等方位信息，尽量隐藏商业 POI 标注，突出 11 图钉；具体能力待验证。

这将替代现役允许缺评分、缺照片的地图显示规则；公开数据的维护和发布仍遵守 public-places.md。

## 界面原型

已按维护者要求进入原型比较：本地分支 `codex/11-map-prototype`。原型位于独立 worktree，不修改现役应用。该分支的 `PROTOTYPE.md` 记录运行方式、比较问题和局限。

- A：全屏地图与浮动详情。
- B：地点目录与地图并排，手机上下排列。
- C：照片和到访信息优先，地图在下。

维护者否决上述三版（历史提交 `b81c05f`），明确要求沿用原始设计。新原型保留原有类别胶囊、头像分类图钉、星级、配色和底部详情抽屉，仅收紧内容与操作入口，并补充到访日期及年龄。

运行 `npm run prototype` 后访问 `http://127.0.0.1:4173/index.html?variant=refined`。底部「原版 / 微调」切换到 `variant=original` 原版视觉对照；两版均不读写浏览器业务存储。最终评阅版本为 `2cc7a85`；维护者已授权据此正式实现，原型不可直接发布。
