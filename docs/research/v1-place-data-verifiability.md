# v1 预制地点与便利设施可验证性调查

调查日期：2026-08-24

代码基线：`origin/main` `9434680`（33 个预制地点位于 `index.html`）

对应决策票：[调查现有地点与便利设施信息的来源和可验证性](https://github.com/meetwk0916/playmap/issues/8)

## 结论

现有 33 个预制地点可作为编辑候选清单，但**不能作为“便利设施均已核实”的 v1 数据集发布**。

- 仓库只保存名称、类别、手写经纬度和标签，没有场馆/地图 POI ID、逐字段来源、核验日期、地址或失效策略。代码注释仅笼统称坐标来自“维基百科 / OpenStreetMap 等”，既无法追溯到单条记录，也把坐标系误写成不存在的“WGS-02”。腾讯位置服务明确使用 [GCJ-02](https://lbs.qq.com/FAQ/latlng_faq.html)。
- 2026-08-24 在生产域名通过腾讯地图 JavaScript SDK 对全部种子进行了附近 POI 核验。多数种子位于对应大型场馆范围内，但种子没有保存腾讯 POI ID，无法证明图钉代表场馆中心、入口还是内部区域；[腾讯地点搜索文档](https://lbs.qq.com/service/webService/webServiceGuide/webServiceSearch)也将 POI ID 定义为地点唯一标识。
- 至少两条建筑级种子存在千米级偏差：上海少年儿童图书馆长风馆种子与腾讯场馆 POI 相差约 1.38 km；上海南翔印象城 MEGA 种子与腾讯场馆 POI 相差约 1.24 km。后者也可由[嘉定区政府给出的地址](https://www.jiading.gov.cn/mspd/g/sc/content_6259)和[高德场馆 POI](https://www.amap.com/place/B0FFK8KCHM)交叉确认。大型公园的“中心点差”不能直接判错，但同样需要明确导航目标语义。
- “上海图书馆东馆（少儿区）”是场馆内部功能区，不是稳定的独立地图 POI；“前滩休闲公园（红砂坑区）”在腾讯 3 km 附近搜索中无同名 POI，政府当前资料使用的是“前滩休闲公园内的**粉红沙滩**”这一名称并说明附近驿站厕所约每公里一处，而不是该点自身拥有厕所（[上海市妇儿工委](http://fegw.sh.gov.cn/ywxx/20260401/5be854c37b39494e88f6371128a3da20.html)）。
- 便利设施标签共 8 种、160 次赋值，其中 `stroller` 覆盖全部 33 个地点。标签没有字段级出处；而且已经存在权威来源直接反例：长风馆官方说明“不具备停车条件”，种子却标记 `parking`（[上海市文旅局](https://whlyj.sh.gov.cn/wbzx/20220719/4d46dca16c1c419f9dd58bc70d4c65af.html)）；上海儿童博物馆要求童车停在指定位置、不得在馆内推行，种子却标记 `stroller`（[场馆参观指南](https://www.shetbwg.cn/p-service_cgzn.html)）。

因此，v1 可以承诺“提供一组经过核验的上海候选亲子地点”，但在建立字段级证据和更新机制前，不能承诺当前 33 个地点的全部坐标、票务和便利设施标签准确、实时或适用于当天出行。

| 字段 / 标签 | 当前数量 | 可验证性 | v1 风险 |
| --- | ---: | --- | --- |

标签赋值总数来自当前种子：`free 18`、`ticket 12`、`stroller 33`、`parking 24`、`toilet 18`、`nursing 15`、`indoor 10`、`food 14`。

## 对 v1 数据承诺的约束

后续“确定地点与便利设施的可信承诺”至少需要在以下边界内做决定：

1. **地点承诺与设施承诺分离。** 当前证据足以保留“上海候选亲子地点”的产品方向，但不支持把 33 条现有便利设施标签整体称为已核实。
2. **导航目标必须有身份。** 每个预制地点至少保存地图供应商、POI ID、官方名称/地址、GCJ-02 坐标、导航目标类型（场馆/主入口/具体区域）和 `verifiedAt`。内部功能区不能伪装成独立 POI。
3. **不承诺未定义的判断词。** `停车方便`、`推车友好`、`餐饮便利`、`室内避暑`若继续存在，必须先给出可复核判定规则；否则应降为可证事实，如“有场馆停车场”“允许童车入馆”“有母婴室”“主要展区室内”。
4. **设施必须逐字段带证据。** 每个标签至少记录一方来源 URL、原始事实摘要、核验日期和限定条件；普通厕所不能映射为亲子卫生间，场馆附近餐饮/停车不能映射为场馆内设施。
5. **时效信息要有有效期。** 门票、预约、营业、停车、餐饮和临时关闭应在显示时标注“核验于 YYYY-MM-DD”，并在超过维护周期或来源失效后隐藏/降级，而不是继续给出肯定标签。
6. **发布前先处理已知反例。** 至少复核长风馆、南翔印象城、上海儿童博物馆、上图东馆、碧海金沙和前滩粉红沙滩；在决策票锁定承诺前，不应把本研究直接当作批量改数据的实施授权。

## 调查局限

- 本调查回答“当前数据能否被追溯和承诺”，不是一次永久有效的场馆运营普查；官方网页本身也会更新。
- 腾讯 SDK 附近搜索受关键词、AOI 大小和结果排序影响。千米级差异是需要人工复核的信号，不单独作为大型公园坐标错误的最终判决。
- 商场和部分景区更常把设施信息放在微信小程序、楼层导览或现场标识中。无法通过公开一方网页复核的字段在本调查中按“未验证”处理，而不是按“不存在”处理。
