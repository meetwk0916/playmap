# 产品决策档案

本文只保留理解现役边界所需的历史结论，不是路线图。当前产品合同见 [README.md](../README.md)，术语见 [CONTEXT.md](../CONTEXT.md)。

## 2026-08-20：记录型单人地图

早期版本围绕“想去/去过、评分、游玩记录、照片和清单”构建。体验走查发现，它擅长记录，却在出行前的高频决策链路上存在三个缺口：

- 地图不能直接按类别筛选；
- 缺少距离与亲子便利设施；
- 选定地点后不能直接导航。

这次走查提供了问题证据，但其评分、版本路线和“持续记录”定位均已退役。

## 2026-08-21：收敛为出行决策

产品目标改为“找地点 → 看关键信息 → 导航出发”，并落实了地图类别筛选、距离、便利设施和腾讯地图导航。清单、评分、想去/去过、游玩记录、照片与设置从日常界面隐藏。

旧数据结构和读写逻辑继续保留，用于兼容已有 `localStorage` 数据；隐藏不等于删除。新迭代不得为了简化代码破坏这条兼容边界。

早期 UI 提案中继续有效的部分只有：地图即首页、类别色、设计令牌、44px 触控目标、键盘焦点和 reduced-motion。双 Tab、清单、记录型详情和社区化添加入口均已退役。

## 暂停方向：社区推荐

社区推荐曾形成 PRD，但当前单人版不包含社区、社交或 UGC。若未来重新立项，必须重新验证：

- 家长是否愿意贡献内容；
- 后端与身份/数据方案；
- 内容审核资源和 SLA；
- 隐私、未成年人保护与 UGC 合规。

旧 PRD 的指标、排期和技术预留不是当前承诺，不应直接进入实现。
