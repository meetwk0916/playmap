# playmap

「11去哪玩」是帮助家长快速决定亲子出行目的地的地图。

## 运行

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/index.html`。应用是单文件原生 HTML/CSS/JavaScript，使用腾讯地图 GL JS API；地点与用户已有历史数据保存在浏览器 `localStorage`，不需要后端。

## 验证

```bash
npm run check:design
npm test
```

`npm test` 使用 Playwright，并自动启动 4173 端口的静态服务器；首次运行前需安装项目依赖及 Playwright Chromium 运行环境。

## 最小使用流程

1. 搜索地点，或按类别筛选地图图钉。
2. 查看距离与亲子便利设施。
3. 点击「导航去这里」立即出发。

用户仍可把地点添加到自己的地图。清单、评分、想去/去过状态、游玩记录、照片与设置不再出现在日常流程中；已有本地数据保持兼容，不会因精简界面而删除。

首次使用会预制 33 个上海亲子地点：15 个公园，以及游乐场、动物园/水族馆、博物馆/科技馆、图书馆、商场儿童区、亲水玩沙各 3 个代表点。“其他”类别不预制，避免缺少明确标准的地点干扰出行决策。已有非空地图会按名称自动补齐新增类别点；用户主动清空后的地图不会被重新填充。

## 产品边界

- 核心任务：快速决定今天去哪并出发。
- 保留：地图、搜索、类别筛选、地点详情、便利设施、一键导航、最简地点添加。
- 不作为主流程：家庭游玩档案、社区推荐、社交互动和成就激励。
