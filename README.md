# 11去哪玩

帮助家长快速完成“找地点 → 看关键信息 → 导航出发”的上海亲子地图。

## 运行

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173/index.html>。应用是单文件原生 HTML/CSS/JavaScript，使用腾讯地图 GL JS API；数据保存在浏览器 `localStorage`，不需要后端。

生产站点为 <https://meetwk.site/playmap/>，由 GitHub Pages 从 `main` 分支根目录发布并强制使用 HTTPS。

## 腾讯地图配置

生产页面使用受域名限制的浏览器 Key 加载腾讯地图 GL JS，并供地点搜索降级通道复用。腾讯位置服务控制台必须允许 `meetwk.site`，同时为地点搜索启用 WebService API 和相应配额。

浏览器 Key 会随页面源码公开，必须依靠域名白名单和额度限制控制使用范围。不要把腾讯地图 SecretKey/SK 写入 HTML、JavaScript 或仓库；如需使用 SK，应改由服务端代理持有。

## 验证

```bash
npm run check:design
npm test
```

`npm test` 使用 Playwright，并自动启动 4173 端口的静态服务器；首次运行前需安装项目依赖及 Playwright Chromium 运行环境。

## 产品范围

1. 搜索地点，或按类别筛选地图图钉。
2. 点击右下角定位按钮，在需要时授权浏览器找到自己的位置。
3. 查看距离，以及停车、童车通行、亲子卫生间、母婴室、场馆内餐饮五项设施信息；每项只显示“有 / 无或受限 / 暂无信息”。
4. 点击「导航去这里」立即出发。

用户也可以从腾讯地图在线搜索结果中选择确切地点，添加到自己的地图；不支持在任意坐标手填名称创建地点。清单、评分、想去/去过状态、游玩记录、照片与设置不属于当前主流程；旧版本地数据仍兼容，不会因界面精简而删除。

地图或在线搜索暂不可用时，页面保留已有地点的本地浏览、类别筛选与详情入口。无法读取或遇到更高版本的本地数据时，应用进入只读保护模式，不覆盖原始内容；只有用户在“数据与隐私”中明确清空后才恢复写入。

“我的位置”只在用户点击定位按钮后请求浏览器权限，用于居中地图、显示临时定位点和计算距离；它不是可添加到“我的地图”的地点，也不会绕过在线 POI 选择流程。

动物园、水族馆、博物馆、科技馆分别提供独立的类别筛选。旧版合并类别只会在地点名称明确包含“水族馆/海洋馆”或“科技馆/科学馆/天文馆”时自动拆分；现有评分、记录和照片不受影响。

首次使用会预制 33 个上海亲子地点：15 个公园，以及游乐场、动物园、水族馆、博物馆、科技馆、图书馆、商场儿童区、亲水玩沙等代表点。“其他”类别不预制，避免缺少明确标准的地点干扰出行决策。已有非空地图会按名称自动补齐新增类别点；用户主动清空后的地图不会被重新填充。

## 发布边界

代码合并、候选部署与真人验收是三件独立的事。候选版本部署后，由 5 个真实上海亲子家庭用自己的手机完成“找地点 → 看详情 → 导航”：至少 4/5 无提示打开正确导航，中位数不超过 2 分钟，至少 4/5 能说清选择理由；错误目的地、数据丢失和完全卡死必须为零。满足这些门槛后才可决定是否发布 v1 标签；仓库测试通过本身不等于已经发布。

截至 2026-08-28，[PR #20](https://github.com/meetwk0916/playmap/pull/20) 已合并并部署到生产站点，设计门禁与 38 项 Playwright 测试通过，生产页面与合并源码一致。当前状态是“v1 候选已上线”，尚未完成 5 个家庭真人验收，也未创建 `v1.0.0` 标签。
